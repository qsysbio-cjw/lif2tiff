# LIF2TIFF Branding

The application icon is an AI-generated raster mark created for LIF2TIFF. It
combines a microscope objective, three acquisition channels, and simplified
microscopy objects. The icon contains no third-party logo or text.

- `lif2tiff-icon-v2.png`: transparent master used by the Qt application.
- `lif2tiff-icon-v2.ico`: multi-resolution Windows executable icon.
- numbered PNG files: fixed-size derivatives for desktop integration.
- `*-chroma.png`: retained generation sources used for reproducible background
  removal and design history.

The earlier unnumbered icon is retained as a rejected first design iteration.
