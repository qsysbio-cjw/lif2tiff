# LIF2TIFF 2.0.0-beta.1

This package contains two programs:

- `GUI/`: the desktop LIF inspection and conversion workbench;
- `lif2tiff` or `lif2tiff.exe`: the terminal CLI.

The complete `GUI` directory must remain together. The CLI is a standalone
single-file executable.

Run `lif2tiff --help` for terminal commands. Original LIF files are treated as
read-only and outputs are never silently overwritten.
