# Development History

The repository intentionally preserves two generations:

- `legacy/readlif-v1/`: the original readlif/customtkinter implementation;
- the repository root: the liffile/PySide6 v2 workbench.

The v2 design and test trail are retained in `development-notes.md` and
`changelog-and-tests.md`. Historical version labels inside those documents are
kept as written because they describe intermediate development snapshots.
